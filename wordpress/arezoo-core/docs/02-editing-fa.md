# راهنمای ویرایش

همه‌چیز با المنتور و ویجت‌های «آرزو» ویرایش می‌شود. هیچ‌جا لازم نیست CSS، HTML یا کد بنویسید.

## جای هر چیز

| چه چیزی | کجا |
|---|---|
| محتوای برگه‌ها | برگه‌ها ← ویرایش با المنتور |
| هدر، فوتر، صفحهٔ تک‌اثر، آرشیو، ۴۰۴ | قالب‌ها ← قالب‌های ذخیره‌شده ← «آرزو — …» ← ویرایش با المنتور |
| منو | نمایش ← فهرست‌ها |
| تم رنگی کل سایت (۹۶ تم) | آرزو ← تم‌های رنگی |
| چیدمان هر بخش (۵ دمو برای هر کدام) | آرزو ← دموها |
| آثار | آرزو ← آثار |
| کالکشن‌ها و نوع‌ها (افزودن، حذف، ترتیب) | آرزو ← دسته‌بندی‌ها |
| ایمیل، اینستاگرام، تلگرام، نام برند | آرزو ← تنظیمات ← برند و تماس |
| اسکچ‌های پس‌زمینهٔ کل سایت | آرزو ← تنظیمات ← پس‌زمینهٔ اسکچ |
| رنگ‌های سراسری و فونت‌ها | المنتور ← تنظیمات سایت |

## ویجت‌های آرزو (دستهٔ «آرزو» در پنل المنتور)

| ویجت | کار |
|---|---|
| صحنهٔ هیرو آرزو | پس‌زمینهٔ زندهٔ هیرو: عکس با ناحیه‌های متحرک، لایه‌های جدا، ویدیوی خودتان یا اسلایدشو |
| پورتفولیوی افقی آرزو | ردیف‌هایی که با اسکرول صفحه افقی حرکت می‌کنند و بعد از توقف، خودکار ادامه می‌دهند |
| کارت‌های روی‌هم آرزو | کارت‌های کالکشن که هنگام اسکرول روی هم می‌چسبند (قابل خاموش کردن) |
| آرشیو کالکشن‌ها آرزو | همهٔ آثار با فیلتر کالکشن و نوع؛ ۵ چیدمان و ۵ موشن متن |
| گالری اثر، فیلد اثر، مشخصات اثر، اثر قبلی و بعدی، آثار مرتبط | اجزای صفحهٔ تک‌اثر |
| سوالات متداول آرزو | ۵ چیدمان، جستجو، دادهٔ ساختاریافته |
| خط زمانی آرزو | خطی که با اسکرول پر می‌شود |
| موشن طراحی آرزو | ۸ موشن طراحی دیجیتال (اسکچ، تراش نگین، لایه‌ها، مدل سه‌بعدی، رنگ‌گذاری، نقشهٔ فنی، مدار، رندر) |
| فرایند طراحی دیجیتال آرزو | مرحله‌های طراحی با عکس‌های شما در قاب تبلت، قلم متحرک و پنل لایه‌ها |
| از اسکچ تا جواهر آرزو | مقایسهٔ اسکچ و طرح نهایی؛ اسکچ از خود تصویر استخراج می‌شود |
| نوار عکس استودیو آرزو | نوار متحرک عکس‌ها |
| لوگو، منو، نوار پایین، راه‌های تماس، طرح اسکچ | اجزای هدر و فوتر و تزئین |

## قابلیت‌های مشترک روی هر کانتینر و ویجت

در زبانهٔ «پیشرفته» هر المان این بخش‌ها اضافه شده‌اند. همه پیش‌فرض خاموش‌اند و هر المان مقدار خودش را دارد.

- **شیشهٔ آرزو:** رنگ، پوشش، تاری، غلظت، خط دور، سایه، برق لبه
- **عمق سه‌بعدی آرزو:** «کج شدن با موس» یا «ضخامت واقعی و قابل فشردن»، با همهٔ تنظیم‌هایش
- **ورود با حرکت آرزو:** ۷ نوع ورود با مدت، تأخیر و فاصله
- **نوار شناور آرزو** (فقط کانتینر): شناور بالا یا پایین، فاصله، عرض، پنهان شدن
- **اسکچ پس‌زمینهٔ آرزو** (فقط کانتینر): یک طرح اسکچ پشت همان بخش با اندازه، جا، شفافیت، رنگ و حرکت
- **خط زمانی آرزو** (فقط کانتینر): کانتینرهای داخلی را به مرحله‌های خط زمانی تبدیل می‌کند

## تم رنگی و تغییرات دستی

اعمال تم فقط ۱۳ رنگ سراسری آرزو و ۴ رنگ اصلی المنتور را عوض می‌کند. بخش‌هایی که دموها می‌سازند به همین رنگ‌های سراسری وصل‌اند و با تم عوض می‌شوند. هر جا در المنتور رنگ دیگری دستی انتخاب کنید، آن رنگ با تغییر تم دست نمی‌خورد.

## دموها

«اعمال» چیدمان مقصد را واقعاً جایگزین می‌کند و بعد در المنتور به‌صورت ویجت‌های عادی دیده می‌شود. قبل از جایگزینی هشدار داده می‌شود و از چیدمان فعلی نسخهٔ پشتیبان نگه داشته می‌شود (تا ۵ نسخه برای هر مقصد). «بازگردانی نسخهٔ قبلی» آخرین نسخه را برمی‌گرداند.

| بخش | مقصد |
|---|---|
| هیرو | بخشی از صفحهٔ اصلی که «شناسهٔ CSS» آن `ay-hero` است |
| آرشیو کالکشن‌ها | بخش `ay-archive` در برگهٔ Collections |
| سوالات متداول | بخش `ay-faq` در برگهٔ Contact |
| دربارهٔ من | کل برگهٔ About Me |
| صفحهٔ تک‌اثر، هدر، فوتر | کل قالب مربوط |

بقیهٔ بخش‌های همان برگه (بالا و پایین بخش جایگزین‌شده) دست نمی‌خورند.

## هیرو

ویجت «صحنهٔ هیرو آرزو» اولین ویجت داخل کانتینر هیرو است و پشت بقیه می‌نشیند؛ عنوان، متن و دکمه ویجت‌های عادی المنتورند. در حالت «عکس با ناحیه‌های متحرک» هر ناحیه یک بیضی نرم است که جا، اندازه، نوع حرکت، شدت و سرعتش را تعیین می‌کنید. با روشن بودن «نمایش ناحیه‌ها در ویرایشگر» بیضی‌ها و محور تاب هر کدام را می‌بینید. با سرعت صفر، یا وقتی بازدیدکننده «کاهش حرکت» را روشن کرده، دقیقاً خود عکس نمایش داده می‌شود.
