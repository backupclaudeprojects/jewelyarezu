# Arezoo Yousefi — سایت نمونه‌کار جواهرات

این مخزن مراحل ساخت سایت نمونه‌کار «Arezoo Yousefi» را نگه می‌دارد. کار در دو مرحله انجام می‌شود:

1. **پیش‌نمایش دموی اصلی** (همین مرحله): یک سایت HTML ساده برای دیدن ظاهر، صفحات و حرکت‌ها.
2. **قالب وردپرس** با ویرایش واقعی در المنتور: در پوشهٔ `wordpress/` و بسته‌های آمادهٔ نصب در `dist/`.

## قالب و افزونه

- `dist/arezoo-core-1.0.0.zip` افزونهٔ همراه و `dist/arezoo-theme-1.0.0.zip` قالب.
- راهنمای نصب: `wordpress/arezoo-core/docs/01-install-fa.md`
- راهنمای ویرایش: `wordpress/arezoo-core/docs/02-editing-fa.md`
- گزارش تست: `wordpress/arezoo-core/docs/03-test-report-fa.md`
- ساخت دوبارهٔ بسته‌ها: `tools/build-zips.sh`

## پیش‌نمایش

پوشهٔ `preview/` یک سایت ایستا است. برای دیدن آن، `preview/index.html` را در مرورگر باز کنید، یا در همان پوشه یک سرور محلی اجرا کنید:

```bash
cd preview && python3 -m http.server 8000
```

این پیش‌نمایش فقط ظاهر و رفتار را نشان می‌دهد. قالب وردپرس نیست و چیزی را دربارهٔ المنتور ثابت نمی‌کند.

- صفحات: خانه، کالکشن‌ها، تک‌اثر، دربارهٔ من، تماس (به‌همراه سوالات متداول) و ۴۰۴.
- دکمهٔ «پیش‌نمایش · تنظیمات» کنار صفحه پنلی فارسی باز می‌کند که جای موقت کنترل‌های المنتور است: ۹۶ تم رنگی (دو پالت ۴۸تایی)، دو دموی هیرو با سرعت و شدت حرکت هر بخش، شیشهٔ هدر و نوار پایین، اسکرول افقی، کارت‌های روی‌هم، موشن دسته‌بندی‌ها، پنج چیدمان سوالات متداول و پترن آبرنگی باکس مشخصات.
- متن سوالات متداول (۱۶ پرسش در ۴ گروه) بدون تغییر از Sogand Core 1.0.6 برداشته شده و در `preview/assets/faq-data.js` است.
- عکس جواهرات، نمونه‌های بستهٔ سوگند هستند. نشانی ایمیل، شناسه‌ها و متن‌های معرفی هم نمونه‌اند.
- هیروی اصلی عکس خود شماست (`preview/assets/img/hero/night-garden.jpg`) که بدون تغییر نمایش داده می‌شود؛ ناحیه‌های آن با `preview/assets/hero-scene.js` حرکت می‌کنند و در حالت سکون دقیقاً همان عکس است.
- هیروی روشن آبرنگی دموی دوم است و لایه‌هایش موقت‌اند. پرامپت ساخت لایه‌های نهایی آن در `docs/hero-art-prompts.md` است.
