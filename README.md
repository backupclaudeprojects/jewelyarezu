# Arezoo Yousefi — سایت نمونه‌کار جواهرات

این مخزن مراحل ساخت سایت نمونه‌کار «Arezoo Yousefi» را نگه می‌دارد. کار در دو مرحله انجام می‌شود:

1. **پیش‌نمایش دموی اصلی** (همین مرحله): یک سایت HTML ساده برای دیدن ظاهر، صفحات و حرکت‌ها.
2. **قالب وردپرس** با ویرایش واقعی در المنتور: بعد از تأیید پیش‌نمایش ساخته می‌شود.

## پیش‌نمایش

پوشهٔ `preview/` یک سایت ایستا است. برای دیدن آن، `preview/index.html` را در مرورگر باز کنید، یا در همان پوشه یک سرور محلی اجرا کنید:

```bash
cd preview && python3 -m http.server 8000
```

این پیش‌نمایش فقط ظاهر و رفتار را نشان می‌دهد. قالب وردپرس نیست و چیزی را دربارهٔ المنتور ثابت نمی‌کند.

- صفحات: خانه، کالکشن‌ها، تک‌اثر، دربارهٔ من، تماس (به‌همراه سوالات متداول) و ۴۰۴.
- دکمهٔ «پیش‌نمایش · تنظیمات» کنار صفحه پنلی فارسی باز می‌کند که جای موقت کنترل‌های المنتور است: ۴۸ تم رنگی، سرعت حرکت هیرو، شیشهٔ هدر و نوار پایین، اسکرول افقی، کارت‌های روی‌هم، موشن دسته‌بندی‌ها، پنج چیدمان سوالات متداول و پترن آبرنگی باکس مشخصات.
- متن سوالات متداول (۱۶ پرسش در ۴ گروه) بدون تغییر از Sogand Core 1.0.6 برداشته شده و در `preview/assets/faq-data.js` است.
- عکس جواهرات، نمونه‌های بستهٔ سوگند هستند. نشانی ایمیل، شناسه‌ها و متن‌های معرفی هم نمونه‌اند.
- لایه‌های آبرنگی هیرو موقت‌اند. پرامپت ساخت لایه‌های نهایی در `docs/hero-art-prompts.md` است.
