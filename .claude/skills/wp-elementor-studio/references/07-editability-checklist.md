# 07 — چک‌لیست ریزبینانهٔ «همه‌چیز قابل ویرایش»

این‌ها خواسته‌های واقعی‌ای است که بعد از نسخهٔ اول یکی‌یکی آمد. از روز اول بسازشان تا درخواست
تکراری نیاید.

## سراسری
- [ ] لوگو (فایل، اندازه برای هر دستگاه، وسط‌چین در موبایل)، favicon / site icon، نام برند.
- [ ] فهرست مرکزی **شبکه‌های اجتماعی** (افزودن/حذف/مرتب‌سازی با کشیدن، نوع شبکه، مقدار، برچسب،
      آیکن سفارشی، روشن/خاموش) که همه‌جا استفاده شود: هدر، فوتر، داک پایین، تماس. هیچ شماره/ایمیلی
      در کد نباشد مگر کاربر وارد کند.
- [ ] کلید سراسری برای هر تاکسونومی/بخش اختیاری (مثل «استفاده از کالکشن‌ها»): خاموش ⇒ همه‌جا پنهان
      (کارت‌ها، تک‌آیتم، فیلترها، breadcrumb به‌شکل «بخش / نام آیتم»)، در ویرایشگر آیتم خاکستری و
      غیرفعال، **داده حذف نشود**.
- [ ] تم رنگی سراسری + رنگ اختصاصی هر آیتم + کلید هر ویجت (سه سطح).
- [ ] تنظیمات سراسری جلوه‌ها (هاله: رنگ، اندازه، شدت، تنفس/پالس، خاموش کامل).
- [ ] پرده/گذار صفحه با سبک‌های متعدد، کاملاً قابل ویرایش.
- [ ] پس‌زمینهٔ کاغذدیواری/اسکچ: انتخاب طرح‌ها، تراکم، وزن و اندازهٔ هر طرح.

## هر ویجت
- [ ] هر متن قابل ویرایش (عنوان، برچسب، دکمه، متن «بیشتر»، متن خالی بودن نتایج).
- [ ] تایپوگرافی/رنگ/hover/تراز/فاصله برای هر بخش متنی؛ ریسپانسیو.
- [ ] نمایش/پنهان هر جزء با کلید (عنوان، برچسب، مشخصات، دکمه، هاله، خط، شماره...).
- [ ] نمایش/پنهان برای دسکتاپ/تبلت/موبایل جداگانه (مخصوصاً آیتم‌های ریپیتر: لینک‌های داک).
- [ ] رفتار موبایل صریح: روی‌هم/زیرهم، شکل قاب تصویر (افقی/عمودی/مربع/هم‌شکل تصویر)، تعداد ستون،
      تعداد مشخصات، حرکت در موبایل، وسط‌چین.
- [ ] آیکن‌ها: داخلی + کتابخانهٔ المنتور + آپلود SVG/تصویر، با رنگ‌پذیری.
- [ ] منبع داده با انتخاب دستی و کوئری، و بازنویسی متن/تصویر/لینک هر آیتم داخل ویجت.
- [ ] چند «حالت» طراحی در یک ویجت، با حالت قدیمی به‌عنوان پیش‌فرض.
- [ ] هر جلوه (tilt، عمق، نور متحرک، درخشش، هاله، رنگ درخشش، شفافیت) کلید جدا.
- [ ] چسبان (sticky) با «تا کدام مرحله/تا انتهای ستون» و فاصله از بالا.

## نوار/داک پایین موبایل و هدر
- [ ] آیتم‌ها با ریپیتر (افزودن/حذف، آیکن، لینک، پنهان در هر دستگاه) بدون شکستن ریسپانسیو (اسکرول
      افقی اگر جا نشد).
- [ ] روی دسکتاپ پنهان تا اسکرول، با انیمیشن جابه‌جایی با هدر؛ کلید برای همه‌چیز.
- [ ] بخش شبکه‌ها: «از تنظیمات سایت / انتخاب از فهرست / سفارشی»، و کلید نمایش در موبایل، دکمهٔ بالا.

## تماس
- [ ] فقط نام/آیکن قابل کلیک (نه دکمه‌های «باز کن / کپی» اضافه)، تراز قابل تنظیم.

## مدارک و افتخارات (یا هر «فایل‌محور»)
- [ ] ریپیتر: عنوان، صادرکننده، سال، فایل (تصویر/PDF)، نمایش در lightbox، دانلود، افزودن/حذف؛
      بخش تا وقتی فایلی نیست روی سایت پنهان.

## ویرایشگر آیتم‌ها (wp-admin)
- [ ] «توضیح کوتاه» (excerpt) با برچسب قابل‌فهم.
- [ ] اولین تصویر گالری ⇒ خودکار تصویر شاخص اگر خالی بود.
- [ ] متاباکس رنگ‌های اختصاصی با پیش‌نمایش زنده.

## ظرافت‌های موبایل که کاربر دید
- [ ] بدون فاصلهٔ خالی بالای هیرو در موبایل.
- [ ] هایلایت آبی لمس حذف.
- [ ] اسکچ/پس‌زمینه روی متن نیفتد.
- [ ] رنگ کارت‌ها در موبایل یکدست (فقط رنگ هاله متغیر).
- [ ] متن ایتالیک ناخواسته نباشد؛ فیلترهای اضافه حذف‌شدنی.
- [ ] کارت‌های روی‌هم کامل دیده شوند (هیچ بخش بریده نشود)؛ اگر متن بلند است تصویر کوچک شود یا
      حالت روی‌هم در موبایل خاموش‌شدنی باشد.

## مستندسازی برای کاربر
- [ ] فایل «راهنمای ویرایش» به زبان کاربر: هر ویژگی ⇒ مسیر دقیق («ویجت X ← تب محتوا ← بخش Y ← کلید Z»).
- [ ] در هر تحویل: «چه چیزی جدید است، کجاست، چه چیزی دست نخورد».
