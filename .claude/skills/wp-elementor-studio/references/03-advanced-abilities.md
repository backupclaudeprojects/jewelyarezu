# 03 — قابلیت‌های تب «پیشرفته» برای همهٔ ویجت‌ها و کانتینرها

هدف: هر ویجتی (حتی ویجت‌های خود المنتور و افزونه‌های دیگر) و هر کانتینر، در تب Advanced چند بخش
تازه بگیرد: «شیشه · برند»، «حرکت · برند»، ... . هیچ‌کدام پیش‌فرض روشن نیستند.

## هوک‌ها
```php
// همهٔ ویجت‌ها: بعد از بخش «استایل» تب پیشرفته
add_action( 'elementor/element/common/_section_style/after_section_end', [ __CLASS__, 'widget' ], 20 );
// کانتینرهای flexbox
add_action( 'elementor/element/container/section_layout/after_section_end', [ __CLASS__, 'container' ], 20 );
// (اختیاری، سایت‌های قدیمی) section/column
add_action( 'elementor/element/section/section_advanced/after_section_end', [ __CLASS__, 'container' ], 20 );
```
داخل هر تابع:
```php
$el->start_controls_section( 'pfx_glass', [ 'label' => 'شیشه · برند', 'tab' => CM::TAB_ADVANCED ] );
$el->add_control( 'pfx_glass_on', [ 'type' => CM::SWITCHER, 'return_value' => 'yes', 'default' => '', 'prefix_class' => 'pfx-glass-' ] );
$el->add_responsive_control( 'pfx_glass_blur', [ 'type' => CM::SLIDER, 'selectors' => [ '{{WRAPPER}}' => '--pfx-gb: {{SIZE}}px;' ], 'condition' => [ 'pfx_glass_on' => 'yes' ] ] );
$el->end_controls_section();
```
⚠️ شناسهٔ بخش و کنترل یکتا و پیشونددار (`pfx_`) — این هوک روی همهٔ عناصر اجرا می‌شود و با هر
افزونه‌ای ممکن است برخورد کند. کنترل‌های کانتینر را جدا تعریف کن (برخی بخش‌ها فقط برای کانتینر معنی دارند).

## الگوی اجرا: کلاس + متغیر، یک handler
- روشن‌خاموش و نوع = `prefix_class` ⇒ CSS خالص هرجا ممکن است.
- مقدارها = متغیرهای CSS روی `{{WRAPPER}}`.
- آنچه CSS نمی‌تواند (نشانگر، اسکرول، چسبان در ستون، شمارنده) = یک اسکنر JS که
  `[class*="pfx-mo-"]` و … را پیدا می‌کند، یک `IntersectionObserver` و یک حلقهٔ rAF مشترک.

## فهرست قابلیت‌هایی که ساخته و استفاده شد (برای هر سایت قابل استفاده)
| قابلیت | کنترل‌ها | پیاده‌سازی |
|---|---|---|
| **شیشه (Glassmorphism)** | blur، اشباع، رنگ/شفافیت پس‌زمینه، حاشیهٔ نوری، نویز | `backdrop-filter` + `::before` گرادیان حاشیه |
| **عمق سه‌بعدی** | کج‌شدن با نشانگر، شدت، پرسپکتیو، لایهٔ نور | handler اشاره‌گر ⇒ `--rx/--ry` |
| **ورود با اسکرول (Reveal)** | نوع (fade/up/scale/blur/clip/mask)، تأخیر، مدت، فاصله، یک‌بار/هربار، پلکانی برای فرزندان | IO ⇒ کلاس `is-in`؛ پلکانی با `--i` |
| **هاله و درخشش** | رنگ، اندازه، تاری، شفافیت، تنفس/پالس | لایهٔ `::after` یا span جدا |
| **حرکت حلقه‌ای** | شناور/چرخش/تاب/ضربان، دامنه، مدت، تأخیر | keyframes با متغیرها |
| **دنبال کردن نشانگر** | شدت، معکوس، فقط دسکتاپ | rAF ⇒ translate |
| **پارالاکس اسکرول** | سرعت، محور، محدوده، خاموش در موبایل | rAF + `getBoundingClientRect` |
| **چسبان در بخش (sticky)** | فاصله از بالا (ریسپانسیو)، تا انتهای ستون/والد، خاموش در موبایل | `position:sticky`؛ اگر والد overflow داشت ⇒ fallback با transform (نگاه کن 09) |
| **نمایش متن** | کلمه‌به‌کلمه/حرف‌به‌حرف/خط، ماسک، رنگ گرادیان در حال حرکت | split در JS، `--i` |
| **افکت تصویر** | زوم hover، سیاه‌سفید→رنگی، تاری، کج، ماسک شکل، آبرنگ | CSS filter/transform |
| **نور گذرا (Shine)** | زاویه، رنگ، مدت، در hover یا حلقه‌ای | گرادیان متحرک `::after` |
| **خط پیشرفت اسکرول** | محل، ضخامت، رنگ | متغیر `--p` 0..1 |
| **نوار شناور (کانتینر)** | چسبیدن بالا/پایین، پنهان قبل از اسکرول، جابه‌جایی با هدر | کلاس روی body بر اساس جهت اسکرول |
| **پس‌زمینهٔ اسکچ/کاغذدیواری (کانتینر)** | انتخاب طرح‌ها، تراکم، وزن و اندازهٔ هر طرح، شفافیت، فقط دسکتاپ | SVG/تصویر تکرارشونده با متغیرها |
| **تایم‌لاین اسکرول (کانتینر)** | خط عمودی که با اسکرول پر می‌شود، نقاط مراحل | متغیر پیشرفت |

## قوانین
- هر قابلیت: کلید «در موبایل هم» یا «خاموش در موبایل»، و احترام به `prefers-reduced-motion`.
- هیچ قابلیتی layout را خراب نکند وقتی خاموش است (فقط کلاس + متغیر؛ بدون wrapper اضافه).
- در ویرایشگر هم کار کند (اسکنر روی `element_ready/global`) ولی انیمیشن‌های ورود در ویرایشگر
  فوراً نمایش داده شوند تا کاربر عنصر نامرئی را گم نکند.
- مستند کن: «پیشرفته ← شیشه · برند» دقیقاً کجاست.
